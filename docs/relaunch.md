# relaunch

[← README로 돌아가기](../README.md)

> Claude Code 새 버전이 설치되면 입력창 위에 알립니다. `/relaunch`를 실행하면 Claude Code를 다시 시작하고 지금 대화를 이어서 엽니다. 자동으로 다시 여는 기능은 Orca 터미널 탭에서만 동작합니다.

## 개요

네이티브 설치판 Claude Code는 실행 중에 새 버전을 내려받아 설치하고 `✔ Update installed · Restart to update`를 표시합니다. 바뀌는 것은 디스크의 실행 파일뿐이고, 지금 실행 중인 Claude Code는 이전 버전 그대로입니다. 새 버전을 쓰려면 `/exit`로 나간 뒤 `claude --resume <세션 id>`로 대화를 다시 열어야 합니다.

relaunch는 이 과정을 줄입니다.

- **업데이트 알림**: 설치된 버전이 지금 버전보다 새로우면 입력창 위에 `Claude Code 업데이트됨 2.1.303 → 2.1.304`와 `다시 열기` 버튼을 표시합니다.
- **다시 열기**: `/relaunch`를 실행하면 지금 Claude Code를 종료하고, 같은 Orca 탭에 `claude --resume <세션 id>`를 입력해 같은 대화를 이어서 엽니다. 설치된 버전이 더 새로우면 새 버전으로 실행됩니다. 대화 기록이 없으면 새 대화를 시작합니다.

하지 않는 것도 있습니다.

- 업데이트를 감지해도 알아서 다시 열지 않습니다. 다시 열기는 항상 사용자가 직접 실행합니다.
- 처음 실행할 때 붙인 옵션(`--model`, `--permission-mode`, `--plugin-dir` 등)은 다시 붙이지 않습니다.
- Orca 밖에서는 Claude Code를 종료하지 않습니다. 직접 입력할 명령만 알려 줍니다.

## 빠른 시작

마켓플레이스를 등록하지 않았다면 먼저 등록하고 모드를 설치합니다.

```
/plugin marketplace add oobg/claude-code-mods
/plugin install relaunch@oobg
```

1. 새 버전이 설치되면 다음 버전 검사 때 입력창 위에 `Claude Code 업데이트됨 2.1.303 → 2.1.304`가 표시됩니다. 검사는 10분 간격이라 설치 직후에는 늦게 표시될 수 있습니다.
2. `다시 열기`를 클릭하거나 `/relaunch`를 실행합니다.
3. Claude Code가 종료된 뒤 같은 탭에서 다시 실행되고 같은 대화가 열립니다. 다시 열린 세션에도 relaunch가 설치돼 있으면 `2.1.303 → 2.1.304로 다시 열었어요` 알림이 표시됩니다.

## 키와 명령

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| `/relaunch` | 확인을 거쳐 Claude Code를 종료하고 같은 Orca 탭에서 다시 엽니다 | 진행 중인 턴이 있으면 턴이 끝난 뒤에 실행됩니다 |
| `/relaunch now` | 작업 중인 에이전트가 있어도 다시 엽니다 | 에이전트의 작업이 중단될 수 있습니다 |
| `다시 열기` 클릭 | `/relaunch`와 같은 확인을 거쳐 다시 엽니다 | 업데이트 알림이 표시될 때. 턴이 진행 중이면 다시 열지 않고 끝난 뒤 누르라고 알립니다 |

## 화면 구성

| 요소 | 내용 | 표시 조건 |
| --- | --- | --- |
| 입력창 위 띠 | `Claude Code 업데이트됨 <지금 버전> → <설치된 버전>`과 `다시 열기` 버튼 | 설치된 버전이 더 새로울 때. next-prompts와 quick-replies 줄보다 위에 표시합니다 |
| `/relaunch` 결과 | 다시 여는 중이라는 안내와 수동으로 다시 여는 명령, 또는 다시 열 수 없는 이유와 수동 명령 | `/relaunch`를 실행할 때 |
| 알림(토스트) | `<이전 버전> → <새 버전>로 다시 열었어요`. 버전이 같으면 `다시 열었지만 버전은 그대로예요` | 다시 열린 세션이 시작할 때 |

## 동작 방식

### 업데이트 감지

엔진에는 업데이트 설치를 알려 주는 이벤트가 없습니다. 세션이 시작하고 5초 뒤에 한 번, 그 뒤로는 10분마다 `claude --version`을 실행해 설치된 버전을 읽고 `$.session.version()`(지금 실행 중인 버전)과 비교합니다. 버전은 숫자 세 개를 숫자로 비교합니다(`2.1.100`이 `2.1.99`보다 새 버전). 검사가 실패하면 알림 없이 다음 차례에 다시 확인합니다.

### 다시 열기

모드에는 Claude Code를 종료하거나 새로 띄우는 기능이 없습니다. relaunch는 종료와 다시 열기를 나눠 처리합니다.

1. 모드가 `$.command.run({ command: 'exit' })`으로 `/exit`과 같은 방식으로 종료합니다.
2. 미리 띄워 둔 도우미 스크립트(`hooks/relaunch.sh`)가 종료를 확인한 뒤 `orca terminal send`로 같은 탭에 `claude --resume <세션 id>`를 입력합니다.

`/relaunch`는 종료하기 전에 다음을 확인합니다. 하나라도 통과하지 못하면 아무것도 종료하지 않고, 이유와 직접 입력할 명령을 출력합니다.

| 확인 | 통과 조건 |
| --- | --- |
| 세션 id | UUID 형식입니다. 셸에 그대로 입력하는 값이라 형식을 확인합니다 |
| Orca 탭 | 환경 변수 `ORCA_TERMINAL_HANDLE`이 있습니다 |
| `orca` 명령 | `orca --version`이 5초 안에 0으로 끝납니다 |
| 에이전트 | `$.agent.list()`에 `pending`, `running`, `waiting` 상태가 없습니다. `/relaunch now`로 무시할 수 있습니다 |
| Orca 탭 상태 | `orca terminal show`가 그 탭이 연결돼 있고(`connected`) 입력을 받을 수 있다고(`writable`) 답합니다. Orca를 다시 시작하면 핸들이 바뀌기 때문입니다 |
| 프로세스 | 모드를 실행 중인 프로세스가 `claude`이고, 터미널(tty)에 연결돼 있으며, 같은 터미널의 셸(`zsh`, `bash`, `fish` 등)이 부모 프로세스입니다 |

대화 기록이 없는 세션은 `--resume`으로 다시 열 수 없어 `claude`만 입력합니다.

### 도우미 스크립트

`hooks/relaunch.sh`는 `nohup`으로 실행돼 Claude Code가 종료된 뒤에도 남습니다. 확실하지 않으면 아무것도 입력하지 않고 끝냅니다.

1. `$TMPDIR/claude-relaunch.<세션 id>` 폴더로 잠급니다. 같은 세션의 도우미가 이미 실행 중이면 끝냅니다. 주인이 없는 잠금은 회수합니다.
2. 0.2초마다 확인합니다.
   - 셸의 시작 시각이 바뀌었으면(셸이 끝났거나 pid가 재사용됨) 포기합니다.
   - claude가 아직 있으면 시작 시각이 같은지 확인합니다. 다르면(pid 재사용) 포기합니다.
   - claude가 없어지고 셸이 포그라운드(`ps -o stat=`에 `+`)로 두 번 연속 확인되면 다음 단계로 넘어갑니다.
3. 0.3초 기다린 뒤 `orca terminal send --terminal <핸들> --text "<명령>" --enter`로 입력합니다.
4. 10분 안에 2단계를 통과하지 못하면 아무것도 입력하지 않고 끝냅니다. `/relaunch`를 실행한 직후 새 턴이 시작돼 종료가 늦어져도 10분까지는 기다립니다.

셸이 포그라운드인지 확인한 뒤 명령을 보냅니다. 다만 셸이 입력을 받을 준비가 됐는지는 확인할 수 없어, 다시 열기에 실패하거나 사용자 입력과 섞일 수 있습니다.

### 상수

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| `ORDER` | `5` | 입력창 위 띠 안의 순서. next-prompts(10), quick-replies(20)보다 위입니다 |
| `FIRST_CHECK_MS` | `5000` | 세션 시작 뒤 첫 버전 검사까지의 시간 |
| `CHECK_EVERY_MS` | `600000` | 버전 검사 간격(10분) |
| `PENDING_TTL_MS` | `660000` | 다시 연 기록을 믿는 시간(11분). 도우미가 기다리는 10분보다 조금 깁니다 |

## 설정과 저장 데이터

모드에 설정 명령이나 옵션은 없습니다.

### `$.store`

| 키 | 값 | 뜻 |
| --- | --- | --- |
| `pending` | `{ sessionId, handle, from, at }` | 다시 열기 직전의 세션 id, Orca 탭 핸들, 버전, 시각. 같은 세션 id나 같은 탭의 새 세션이 시작되면 알림을 표시하고 지웁니다. 11분이 지난 기록은 알림 없이 지웁니다 |

### `$.state`

| 키 | 값 | 뜻 |
| --- | --- | --- |
| `installed` | `{ from, to }` 또는 `null` | 지금 버전과 더 새로운 설치 버전. `null`이 아니면 띠를 표시합니다 |

## 외부 호출과 사용량

relaunch 자체는 모델을 호출하지 않아 토큰을 쓰지 않습니다. 실행하는 명령(`claude`, `orca`)과 다시 시작한 Claude Code의 네트워크 동작은 relaunch가 제어하지 않습니다.

| 하위 프로세스 | 언제 | 제한 시간 | 실패 시 |
| --- | --- | --- | --- |
| `claude --version` | 세션 시작 5초 뒤, 그 뒤 10분마다 | 5초 | 다음 차례에 다시 확인합니다 |
| `orca --version` | `/relaunch`를 실행할 때 | 5초 | 종료하지 않고 수동 명령을 안내합니다 |
| `/bin/sh -c 'ps ...'` | `/relaunch`를 실행할 때. claude와 부모 셸을 확인합니다 | 5초 | 종료하지 않고 수동 명령을 안내합니다 |
| `/bin/sh -c 'nohup /bin/sh relaunch.sh ... &'` | 확인을 통과했을 때 | 지정하지 않음 | 종료하지 않고 수동 명령을 안내합니다 |
| `orca terminal send` | 도우미가 종료를 확인했을 때 | 지정하지 않음 | 탭이 셸에 머뭅니다. `/relaunch` 결과에 남은 명령으로 다시 엽니다 |

## 제한 사항

- **Orca 전용입니다.** 다른 터미널에는 모드가 탭에 글자를 입력할 방법이 없어, 종료하지 않고 수동 명령만 알려 줍니다.
- **처음 실행할 때 붙인 옵션은 다시 붙지 않습니다.** 모드는 실행 옵션을 읽을 수 없습니다. 실행 중 바꾼 모델과 권한 모드도 다시 열면 기본값으로 돌아갈 수 있습니다.
- **백그라운드 셸 작업은 확인하지 않습니다.** 모드가 확인할 수 있는 것은 에이전트뿐입니다. 백그라운드로 실행 중인 명령은 종료와 함께 끊길 수 있습니다.
- **셸 준비 여부는 최선의 확인입니다.** 셸이 포그라운드인지까지만 확인합니다. Claude Code가 종료된 직후 사용자가 직접 입력하면 그 입력과 섞일 수 있습니다.
- **npm으로 설치한 Claude Code는 확인하지 않았습니다.** 프로세스 이름이 `claude`가 아니면(`node`) 다시 열지 않고 수동 명령을 안내합니다.

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 업데이트 알림이 표시되지 않습니다 | 터미널에서 `claude --version`이 새 버전을 출력하는지 확인합니다. 세션 시작 5초 뒤와 10분마다 확인하므로 설치 직후에는 늦게 표시될 수 있습니다 |
| `Orca 터미널 탭에서만 자동으로 다시 열 수 있어요` | Orca 밖에서 실행한 Claude Code입니다. 안내된 명령으로 직접 다시 엽니다 |
| `이 claude를 띄운 셸을 확인하지 못했어요` | 셸이 아니라 다른 프로그램이 claude를 실행했을 수 있습니다(예: `exec claude`, 스크립트 안에서 실행). 안내된 명령으로 직접 다시 엽니다 |
| 종료된 뒤 다시 열리지 않습니다 | `/relaunch` 결과에 남은 `claude --resume <세션 id>`를 입력합니다. 화면에 남아 있지 않으면 `claude --resume`만 입력해 세션 목록에서 대화를 고릅니다 |
| 다시 열렸는데 알림이 없습니다 | 다시 열린 세션에 relaunch가 설치돼 있지 않거나(예: `--plugin-dir`로만 붙였던 경우), 다시 열기까지 11분 넘게 걸렸습니다 |
