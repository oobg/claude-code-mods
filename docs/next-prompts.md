## 동작

- Claude가 답을 내고 턴이 끝나면 작은 모델(haiku)을 한 번 호출해 다음 요청을 최대 3개 받는다. 모델에는 2~3개를 요청하지만, 60자를 넘거나 겹치는 줄은 버리므로 1개만 남을 수도 있다.
- 사용자가 중단한 턴, 거절이나 API 오류로 끝난 턴에는 제안을 만들지 않는다. 답 본문(그 턴에 Claude가 마지막으로 보여 준 글)이 120자보다 짧을 때도 만들지 않는다. 생각만 하고 글을 남기지 않은 턴은 본문이 비어 있으므로 여기에 해당한다.
- 번호는 항상 `$1`부터 시작한다. 입력창에 `$1`을 입력하면 그 자리에 1번 문구가 들어간다. 번호를 클릭하면 문구를 입력창에 넣고 제안을 닫는다. 문구를 클릭하면 바로 보낸다.
- `닫기`를 클릭하면 제안을 닫는다. 닫은 제안은 다시 열 수 없고, 다음 턴이 위 조건을 채우고 끝나면 새 제안이 나타난다.
- Claude가 작업하는 동안에는 제안을 숨긴다. 새 프롬프트를 보내면 제안을 지운다.

### 나타나는 모양

0.7.0부터 제안이 한 줄씩 차례로 나타난다.

- 줄은 120ms 간격으로 하나씩 시작하고, 한 줄은 약 320ms에 걸쳐 앞에서부터 글자가 채워진다. 화면은 40ms마다 갱신한다.
- 글자가 채워지는 동안에는 흐린 색으로 보이고, 다 나오면 보통 색으로 바뀐다.
- `다음 제안` 제목 줄과 `닫기`는 첫 줄과 함께 나타난다. 아직 나오지 않은 줄은 빈 줄로 자리를 잡아 두어 입력창 위 영역의 높이가 흔들리지 않는다.
- 애니메이션 도중에도 `$1`을 입력하거나 번호나 문구를 클릭하면 화면에 보이는 일부가 아니라 전체 문구를 넣거나 보낸다.
- 애니메이션 도중 `닫기`를 클릭하거나 새 프롬프트를 보내면 그 자리에서 멈춘다. 모드 코드를 다시 불러와도(핫 리로드) 제안은 남고, 남은 애니메이션 없이 전체 문구로 보인다.

## 모델 호출

- 제안은 사용자의 Claude Code 세션과 같은 계정으로 haiku를 호출해 만든다. 따라서 호출할 때마다 사용자의 Claude Code 사용량에 포함된다. 호출 한 번에 응답은 200토큰까지 받고, effort는 `low`로 둔다.
- 모델에 보내는 내용은 사용자가 마지막으로 보낸 요청의 끝 1000자와 Claude 답 본문의 끝 4000자뿐이다. 답 본문에 들어 있지 않은 대화 기록이나 도구 실행 결과는 따로 보내지 않는다.
- 호출이 20초 안에 끝나지 않거나, 오류가 나거나, 쓸 만한 제안이 없으면 아무것도 표시하지 않는다. 오류 메시지도 띄우지 않는다.
- 제안을 기다리는 사이에 새 프롬프트를 보내면, 늦게 도착한 제안은 버린다.
- 호출만 끄는 설정은 없다. 모델 호출을 멈추려면 이 모드를 끈다.
